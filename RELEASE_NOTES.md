# DeltaRay v0.2.2

## What's new

- **Center-locked home screen.** The connect button now sits exactly in the
  center of the page; the brand label is anchored above it and the status text
  below it, so nothing shifts when extra content appears. The watchdog/traffic
  block simply shows at the bottom after connect.
- **No hint clutter.** The "Start ZeroDPI, then L×Box" hint under the button
  is gone.
- **Update dialog redesigned.** The dialog now matches the app theme (dark
  graphite surface, gold accents) and offers a single **Download from GitHub**
  action that opens the **direct APK file** link in the browser — no release
  page, no Telegram.
- **Update prompt on every launch.** The update dialog appears on each launch
  while a newer release is available; "Not now" no longer permanently
  suppresses it.
